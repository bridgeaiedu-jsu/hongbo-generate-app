# 홍보자동화

매장 사진을 인스타그램용으로 자동 변환하고, 로고를 합성하고, 채널별 홍보 문구까지 한 번에 만들어주는 자동화 도구입니다.

브릿지 커피 매장 운영을 위해 만들었으며, 비개발자도 바탕화면 아이콘 더블클릭 한 번으로 사용할 수 있도록 설계했습니다.

## 하는 일

1. **사진 변환**: `사진` / `자료` 폴더의 jpg, png 사진을 인스타그램용 정사각형(1080x1080)으로 자동 변환합니다. 가운데 기준으로 잘라서 찌그러짐이 없습니다.
2. **로고 합성**: `로고.jpg` 또는 `로고.png`가 있으면 사진 오른쪽 아래에 자동으로 넣습니다. 로고가 들어갈 자리의 배경 밝기를 분석해서, 배경이 어두우면 흰색, 밝으면 검은색으로 로고 색을 자동으로 바꿔 항상 눈에 띄게 합니다.
3. **홍보 문구 생성**: `가게정보.txt`(또는 `가게 정보.txt`)를 읽어서 채널별 홍보 문구를 자동으로 만듭니다.
   - 인스타그램용: 감성형 / 정보형 / 이벤트형 3가지 + 해시태그 10개
   - 네이버 블로그용: 300자 내외의 소개글
   - 카카오톡 단골 공지용: 3줄 이내의 짧은 공지

생성되는 문구는 `자료/내 말투.txt`에 담긴 실제 사장님 글을 분석해서, 이모지 없이 담백한 "~습니다"체로 사장님이 직접 쓴 것처럼 나오도록 맞춰져 있습니다.

## 사용법

바탕화면의 **"홍보물 만들기"** 아이콘을 더블클릭하면 됩니다.

또는 터미널에서 직접 실행:

```
python 인스타변환.py
```

자세한 사용 순서는 [`사용설명서.txt`](사용설명서.txt)를 참고하세요.

## 폴더 구조

```
홍보자동화/
├── 인스타변환.py       # 메인 스크립트
├── 홍보물만들기.bat     # 더블클릭 실행용
├── 로고.png            # 매장 로고 (선택)
├── 사진/               # 변환할 사진을 넣는 곳
├── 자료/               # 가게정보.txt, 말투 샘플, 참고 사진 등
└── 완성/               # 변환된 사진 + 홍보문구.txt가 저장되는 곳
```

## 준비물

- Python 3
- Pillow (`pip install pillow`)

## 매주 할 일

`자료/가게 정보.txt`의 "이번 주 홍보할 것" 부분만 이번 주 소식으로 바꿔 쓴 뒤, 아이콘을 더블클릭하면 사진과 문구가 새로 만들어집니다.
