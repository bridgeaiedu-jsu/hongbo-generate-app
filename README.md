# 홍보 자동화 (브릿지 커피)

매장 사진을 인스타그램용으로 바꾸고, 채널별 홍보 문구를 한 번에 만들어 주는 작은 프로그램입니다.
프로그램을 잘 모르는 가게 사장님이 혼자 쓸 수 있게 만들었습니다.

## 웹에서 바로 쓰기

https://bridgeaiedu-jsu.github.io/hongbo-generate-app/

브라우저에서 사진을 고르면 같은 규칙(1080 x 1080, 로고 라벨)으로 바꿔 주고, 채널별 문구를 보여 줍니다.
사진은 서버로 올라가지 않고 브라우저 안에서만 처리됩니다. (`index.html`, `style.css`, `main.js`, `captions.js`)
문구는 `captions.js`에 들어 있으며 `사진변환.py`의 문구와 같은 내용으로 맞춰 둡니다.

아래는 내 컴퓨터에서 파이썬으로 쓰는 방법입니다.

## 하는 일

- `자료` 폴더의 jpg, png 사진을 **1080 x 1080 정사각형**으로 만듭니다.
  - 사진 가운데를 기준으로 자르고, 늘리거나 찌그러뜨리지 않습니다.
  - 원본 사진은 수정하지 않습니다.
- 사진 오른쪽 아래에 **로고**(`자료/로고.png`)를 넣습니다.
  - 가로 폭의 15%, 가장자리에서 40px 안쪽, 반투명한 흰색 둥근 라벨 위에 얹습니다.
  - 로고 파일이 없으면 오류 없이 로고 없이 진행합니다.
- 채널별 문구를 `완성/홍보문구.txt` 한 파일에 저장합니다.
  - 인스타그램: 감성형 / 정보형 / 이벤트형 3개 + 해시태그 10개
  - 네이버 블로그: 제목 + 본문 약 700~1,000자 + 해시태그
  - 카카오톡 단골 공지: 3줄 이내 존댓말
- 결과 사진은 `완성/오늘날짜_01.jpg` 형식으로 저장됩니다.

## 폴더 구성

| 파일 / 폴더 | 설명 |
| --- | --- |
| `자료/` | 변환할 사진, `로고.png`, `가게 정보.txt`, `내 말투.txt` |
| `완성/` | 결과 사진과 `홍보문구.txt` (지난 결과는 `완성/이전/`에 보관) |
| `사진변환.py` | 사진 변환, 로고 넣기, 문구 저장 |
| `홍보물만들기.py` | 지난 결과를 `완성/이전/`으로 옮긴 뒤 `사진변환.py`를 실행하고 `완성` 폴더를 엽니다 |
| `index.html` `style.css` `main.js` `captions.js` | 웹 버전 (GitHub Pages) |
| `사용설명서.txt` | 비개발자용 매주 사용 순서 |
| `CLAUDE.md` | Claude Code와 작업할 때 지키는 규칙 |

## 준비

- Windows, Python 3
- Pillow 라이브러리: `pip install pillow`

## 실행

```
python 홍보물만들기.py
```

사진만 변환하고 싶다면(이전 결과를 옮기지 않고 이어서 번호를 붙임):

```
python 사진변환.py
```

## 문구는 어떻게 만들어지나요

문구는 프로그램이 스스로 쓰지 않습니다. `자료/가게 정보.txt`와 `자료/내 말투.txt`를 바탕으로
Claude가 문구를 써서 `사진변환.py` 안(`CAPTIONS`, `BLOG_BODY`, `KAKAO`)에 넣어 두는 방식입니다.
그래서 이번 주 홍보 내용이 바뀌면 `가게 정보.txt`를 고친 뒤 Claude에게 문구를 새로 써 달라고 요청해야 합니다.
자세한 순서는 `사용설명서.txt`를 참고하세요.

## 직접 조절할 수 있는 값

`사진변환.py` 위쪽의 숫자로 로고 모양을 바꿀 수 있습니다.

| 이름 | 기본값 | 의미 |
| --- | --- | --- |
| `LOGO_RATIO` | 0.15 | 로고 가로 폭 비율 |
| `MARGIN` | 40 | 사진 가장자리와 로고 사이 간격(px) |
| `PADDING` | 14 | 로고 둘레 흰 여백(px) |
| `LABEL_ALPHA` | 130 | 흰 라벨 불투명도 (255가 완전 불투명) |
