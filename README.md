# 홍보물 자동 생성기

가게 사진과 가게 정보 텍스트 파일만 넣으면, 인스타그램용 정사각형 사진(로고 워터마크 포함)과
인스타그램 / 네이버 블로그 / 카카오톡 공지용 홍보 문구를 한 번에 만들어주는 자동화 도구입니다.

## 하는 일

1. `자료` 폴더에 있는 사진(jpg, png)을 1080x1080 정사각형으로 가운데 기준 크롭
2. 오른쪽 아래에 흰 배경 박스와 함께 로고(`자료/로고.png`) 워터마크 삽입
3. `자료/가게 정보.txt`를 읽어 감성형 / 정보형 / 이벤트형 톤으로 홍보 문구 생성
   - 인스타그램용 (해시태그 10개 포함)
   - 네이버 블로그용 (약 300자, 해시태그 없음)
   - 카카오톡 단골 공지용 (3줄 이내)
4. 결과물을 `완성` 폴더에 `오늘날짜_01.jpg`, `홍보문구.txt`로 저장

## 사용 방법

자세한 사용법은 [사용설명서.txt](./사용설명서.txt)를 참고하세요. 요약하면:

1. `자료` 폴더에 이번 주 사진을 넣는다
2. `자료/가게 정보.txt`에서 "이번 주 홍보할 것" 두 줄만 수정한다
3. 바탕화면 "홍보물만들기" 아이콘을 더블클릭하거나 아래 명령어를 실행한다

```
python instagram_resize.py
```

## 폴더 구조

```
홍보자동화/
├── instagram_resize.py   # 메인 스크립트
├── 홍보물만들기.bat        # 더블클릭 실행용 배치 파일
├── 자료/                 # 원본 사진 + 가게 정보.txt + 로고.png (입력)
└── 완성/                 # 변환된 사진 + 홍보문구.txt (결과물)
```

## 필요 환경

- Python 3
- [Pillow](https://pypi.org/project/Pillow/) (`pip install Pillow`)
